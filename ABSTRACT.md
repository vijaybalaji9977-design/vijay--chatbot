# 📄 Project Abstract

## AI-Powered Multi-Functional Chatbot

The **AI-Powered Multi-Functional Chatbot** is an intelligent conversational system designed to interact with users in a simple, natural, and user-friendly manner. The main objective of this project is to develop a chatbot with multiple features similar to modern AI assistants, allowing users to perform different tasks through a single platform.

The proposed chatbot can understand user queries and generate relevant responses using Artificial Intelligence and Natural Language Processing (NLP). It provides multiple options such as:
1. **General Question Answering**
2. **Text Generation**
3. **Text Summarization**
4. **Translation**
5. **Coding Assistance**
6. **Study Assistance**
7. **Content Creation**
8. **Basic Problem Solving**

The system maintains the context of a conversation to provide more meaningful responses across multiple turns.

The chatbot is designed with an easy-to-use interface where users can enter their questions and receive responses instantly. Additional features include:
- **Chat History & Management** (SQLite persistent storage, conversation search, rename, delete, clear)
- **New Chat** (Instant conversation resets)
- **Copy Response** (One-click clipboard copying of responses & code blocks)
- **Regenerate Response** (Re-query and recreate answers)
- **Clear Conversation** (Wipe message history cleanly)
- **Different Task Modes** (Dedicated modes with quick prompt chips)

The system is developed using modern technologies:
- **Python** (Backend runtime)
- **FastAPI & Uvicorn** (High-performance async REST & Server-Sent Events SSE API)
- **NLP & SymPy** (Natural Language Processing, auto-intent detection & computer algebra)
- **Machine Learning & Cloud APIs** (Google Gemini, OpenAI GPT-4o, Groq Llama 3, OpenRouter, and Built-in Offline Intelligent Engine)
- **HTML5, CSS3, JavaScript** (Modern responsive glassmorphic SPA)

Enhanced capabilities:
- **🎙️ Voice Input and Output** (Web Speech Recognition STT & Speech Synthesis TTS with pitch and rate controls)
- **📄 Document / File Interaction** (PDF, DOCX, TXT, CSV, JSON, Markdown, Code file ingestion & Q&A)
- **🖼️ Image Understanding & Vision** (Image upload, preview, multimodal visual reasoning via Gemini/GPT-4o vision + offline image inspector)
- **🌐 Multilingual Support & Polyglot Engine** (30+ languages with phonetics and grammar notes)
- **⭐ Response Feedback System** (Thumbs up/down feedback and database statistics)

Overall, this project provides a **single intelligent platform for communication, learning, coding, content creation, and everyday assistance**, offering users a flexible, modern chatbot experience.
